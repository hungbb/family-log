# Passwords no account may use (FR-A2, task B1.2).
#
# Compared case-insensitively against the whole password, not as substrings: the goal is to block
# the handful of values that appear in every credential-stuffing list, not to run a dictionary
# attack against the person choosing one.
#
# Only entries of at least PasswordPolicy.MIN_LENGTH characters can ever match — anything shorter is
# already refused for length. With the floor at eight (FR-A2), the eight- and nine-character block
# below is the part that earns its keep: that length is exactly where the passwords in every breach
# corpus sit, and they are legal on length alone.
#
# Vietnamese keyboard-walk and name patterns are included because this product's users are
# Vietnamese and the English-only lists that ship with most libraries miss them entirely.
#
# One entry per line. A larger list (the standard 10k) is a Phase 8 hardening item; keeping this
# one short and readable is worth more now, as long as the common short passwords are covered.
